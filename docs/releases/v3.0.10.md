# v3.0.10 🦕 Iguanodon — the Recovery tool can download itself, and shares the app's version

A follow-up to [v3.0.9](v3.0.9.md). The cryptography, container format,
wordlist, and self-tests are untouched; the Recovery tool's decryption core
is byte-identical to every release since v2.9.0.

## Changes

- **The live Recovery tool now offers its own download.** v3.0.9 made the
  app's footer link open the live recovery page, which left someone on that
  page with no way to get the file onto their disk. Its footer now ends with
  **Download this tool** and keep it next to your encrypted data, serving
  the release asset. Offline, where the link cannot work, nobody needs it:
  they already have the file.
- **The Recovery tool's version now matches the app's.** Since v3.0.6 the
  recovery file carried its own version, bumped only when the file changed,
  so it read v3.0.6 while the app read v3.0.9. Both now show the same
  release number. Every release re-stamps the recovery file, and the
  `SHA256SUMS.txt` of the release named in the footer is the checksum to
  verify a copy against.

## For users

Nothing to do. A copy of the Recovery tool downloaded from an earlier
release still works exactly as before; only the label and the footer link
differ.
