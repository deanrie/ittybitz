# v3.0.6 🦕 Iguanodon — the Recovery tool shows its version

A small follow-up to [v3.0.5](v3.0.5.md). The cryptography, the container
format, and the Recovery tool's decryption core are untouched.

## Changes

- **The Recovery tool now shows its version.** Its footer ends with
  **IttyBitz Recovery v3.0.6**. Until now, someone holding an old copy on a
  USB stick had no way to tell which release it came from.

  The label is the version of the *file*, not of the app. It changes only in
  a release that changes the Recovery tool itself, so two copies with the
  same label are byte-identical. To check a copy you find later, compare its
  checksum against `SHA256SUMS.txt` from the release its label names.

- **Corrected size in the READMEs.** The Recovery tool is now 27 KB; the
  READMEs still said 26 KB, a figure from v2.9.0.

## For users

Nothing to do. Existing `.ibitz` files and encrypted text decrypt exactly as
before. If you keep a copy of the Recovery tool alongside your encrypted
data, this release's copy is the first one that tells you which version it
is; older copies still decrypt everything this one does.
