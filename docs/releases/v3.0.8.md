# v3.0.8 🦕 Iguanodon — the Recovery tool, explained and downloadable

A small release about the Recovery tool's visibility, building on
[v3.0.7](v3.0.7.md). The cryptography, container format, wordlist, and
self-tests are untouched, and the Recovery tool itself is byte-identical to
v3.0.6 (its label stays **IttyBitz Recovery v3.0.6**).

## Changes

- **The footer's recovery link is now a download.** It used to open the live
  recovery page, which is of no use to someone already looking at the live
  app. It now reads **Download recovery tool** and serves the release asset,
  the same way **Download app** does, so the file lands on disk where it
  belongs: next to your encrypted data.
- **The page now says the Recovery tool exists.** Until now nothing on the
  app explained that a standalone decrypt-only file is available. A feature
  card, **Recoverable without us**, replaces the "No Accounts" card and
  describes the file in two sentences with a download link. The hero line
  ends with "Recoverable without us", linking to the same download.

## For users

Nothing to do. If you keep encrypted files, download the Recovery tool once
from the footer or the feature card and store it alongside them.
